# Security Policy

## Supported versions

Security fixes are applied to the latest release of `xanoscriptlint`.

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/bitwisedesign/xanoscriptlint/security/advisories/new).

Do not open a public issue for a suspected vulnerability.

We will acknowledge the report and follow up with a fix or a reasoned decline.
